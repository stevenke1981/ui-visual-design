# 交付前驗收清單

逐項檢查；回報時寫出「已驗證（如何）」與「未驗證」。

## 自動
- [ ] `contrast.py --css --list` 後以真實 token 跑 `--pairs`，每個主題區塊全部 PASS；涵蓋焦點色、輸入框邊框、按鈕字／底、狀態色文字、半透明底上的文字。
- [ ] `shot.mjs` 產出 360 / 768 / 1280 × 淺 / 深截圖，**每張都看過**；主要狀態（錄音中、錯誤、空、已完成）用 `--state` 預覽並看過。
- [ ] 專案既有測試全過；DOM id / API 契約未破壞。
- [ ] `shot.mjs` 全部 OK（無 OVERFLOW、無 JS errors 或已說明原因）。

## 看截圖時問
1. 三秒內看得出這畫面最重要的動作嗎？它是最突出的嗎？
2. 層次：標題、內文、次要文字是否明顯三級？有沒有到處粗體？
3. 間距：是否一致（同一刻度）？區塊之間比區塊內部寬鬆？
4. 顏色：強調色只出現在可互動或狀態處？中性色沒有純灰／純黑？
5. 深色模式：沒有刺眼的純白大面積、沒有看不清的強調色、表面層級可辨？
6. 長字串（中文檔名、網址）有沒有換行或截斷而不撐破？
7. 空狀態、錯誤、停用、載入中都長得合理？
8. 數字等寬、計時器不跳動？
9. 動畫是否尊重 reduced-motion？

## 鍵盤與輔助
- [ ] Tab 順序符合視覺順序；焦點框兩主題都看得見。
- [ ] 主要動作開啟時自動聚焦；Enter / 快捷鍵可用，且 UI 上有標示。
- [ ] 狀態變化有 `aria-live` 或 `role="status"`；錯誤 `role="alert"`。
- [ ] 不只靠顏色表意（有文字、圖示或形狀）。

## 誠實
- [ ] 所有計量、進度、波形來自真實資料；預覽值有明示。
- [ ] 回報中沒有把「看過靜態截圖」說成「功能已驗證」。
